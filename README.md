PG Restore - build kit
======================

1. Copy the PostgreSQL tools into  pgsql\bin  (see the note inside that folder).
2. Make sure Python is available:
     - installed on this PC (python.org installer, "Add python.exe to PATH" ticked), or
     - a portable Python with tkinter + pip in a folder named  python  next to build_standalone.bat
3. Double-click  build_standalone.bat
4. Your app is in  dist\PG Restore\  (and  PG Restore.zip  is ready to share).
   Run  PG Restore.exe  inside that folder.

If something fails, copy the text shown in the black window and send it to Claude.
